# claudegotchi

A menu-bar Tamagotchi for Claude Code.

It lives in your macOS menu bar as an 8-bit pixel pet that watches what Claude
is doing — feed it tokens, keep it company during long sessions, level it up
over time. Neglect it and it gets sad, sick, then leaves.

## Status

Design phase. See `docs/specs/` for in-progress design.
